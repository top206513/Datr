# Railway Last

Веб-приложение для планирования свидания: карта проверенных мест, отсчёт до встречи,
атмосферный музыкальный плеер и чек-лист подготовки — всё на одной странице.

> «Последний поезд уходит в 00:41. Всё, что нужно успеть до него, — здесь».

Проект вырос из простой мысли: идеальный вечер — это не импровизация, а десяток
заранее закрытых мелочей. Приложение держит их в одном месте и оставляет вам
только сам вечер.

---

## Возможности

### 🗺 Карта и локации

- Двенадцать кураторских мест на интерактивной карте (Leaflet + OpenStreetMap).
- Фильтры по категориям (виды, прогулка, ужин, культура, кофе, поздний вечер),
  избранное и поиск по названию, району и тегам.
- Детальная карточка: описание, личный совет, рейтинг, бюджет, лучшее время,
  продолжительность, теги и точные координаты — с копированием в буфер и
  переходом во внешние карты.
- Список и карта синхронизированы: наведение подсвечивает точку, клик по точке
  открывает карточку. Любое место можно назначить местом свидания — оно попадёт
  в шапку и в виджет отсчёта.
- Если подложка карты не загрузилась (нет сети), точки и карточки продолжают работать.

### ⏳ Таймер обратного отсчёта

- Дни, часы, минуты и секунды с анимацией смены разрядов и корректным русским
  склонением («1 день», «2 дня», «5 дней»).
- Дата, название вечера и выбранное место сохраняются в `localStorage`.
- Отсчёт считается от системных часов, а не накоплением тиков, — не сбивается
  после сна вкладки; за час до встречи виджет начинает «гореть».
- Отдельное состояние для уже прошедшей даты.

### 🎵 Музыкальный плеер

Плеер не проигрывает файлы — он **синтезирует музыку прямо в браузере** через
Web Audio API. Ни одного мегабайта ассетов, полная работа офлайн.

- Четыре трека, описанных как партитуры: сетка аккордов, мелодическая фраза,
  темп, тембр и плотность шумовой подложки (см. `src/data/tracks.ts`).
- Голоса: бас, педальный пад из трёх расстроенных осцилляторов, ведущая мелодия
  с лёгким портаменто и редкие колокольчики. Всё это идёт через реверберацию на
  сгенерированной импульсной характеристике и лимитер.
- Play/pause, предыдущий/следующий трек, перемотка по прогресс-бару, громкость
  (сохраняется), плейлист, эквалайзер-визуализатор, автопереход к следующему треку.
- Ноты планируются окнами вперёд (lookahead 0.4 с), поэтому перемотка и пауза
  отзываются мгновенно и не «уезжают» по времени.

### ✅ Чек-лист подготовки

- 14 пунктов в трёх разделах: «за несколько дней», «образ», «в день свидания» —
  купить цветы, подтвердить время, погладить рубашку, выйти на 15 минут раньше.
- У каждого пункта — короткая подсказка, зачем он нужен.
- Свои пункты добавляются и удаляются, прогресс считается кольцевым индикатором,
  отметки переживают перезагрузку, есть сброс.

### 🌙 Оформление

Тёмная «вечерняя» палитра: винный сумрак, золото фонарей, матовое стекло,
плёночное зерно и парящая пыль в воздухе. Адаптивно от 360 px, анимации
на Framer Motion, поддержка `prefers-reduced-motion`, доступные состояния
фокуса и корректные ARIA-подписи.

## Стек

| Что | Чем | Почему |
| --- | --- | --- |
| Каркас | React 19 + TypeScript (strict) | Типы на доменной модели ловят ошибки до рантайма |
| Сборка | Vite 8 | Мгновенный dev-сервер, сборка за ~0.4 с |
| Стили | Tailwind CSS 4 | Дизайн-токены живут в `@theme` прямо в CSS |
| Анимации | Framer Motion | Layout-анимации фильтров и списков «из коробки» |
| Карта | Leaflet + OpenStreetMap | Без API-ключей и лимитов; тёмная тема — CSS-фильтром |
| Звук | Web Audio API | Музыка синтезируется, а не грузится |
| Тесты | Vitest | 30 тестов на чистую логику времени и синтеза |
| Хранение | `localStorage` | Данные не покидают браузер |

Внешних сервисов, ключей и бэкенда нет — приложение полностью статическое.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

Другие команды:

```bash
npm run build      # проверка типов + продакшен-сборка в dist/
npm run preview    # локальный просмотр собранной версии
npm run test       # прогон тестов
npm run typecheck  # только проверка типов
```

Требуется Node.js 20+.

## Как поменять содержимое под себя

- **Свои места** — `src/data/locations.ts`. Координаты берутся с любой карты;
  карта сама подстроит масштаб под новый набор точек. Стартовый центр — `CITY_CENTER`.
- **Свои пункты подготовки** — `src/data/checklist.ts` (или прямо в интерфейсе,
  через форму внизу раздела).
- **Своя музыка** — `src/data/tracks.ts`: корневая нота в герцах, сетка аккордов
  в полутонах, мелодическая фраза (32 восьмых = 4 такта), темп, тембр и плотность шума.
- **Палитра и шрифты** — блок `@theme` в `src/index.css`.

## Приватность

Дата, отметки, избранное и громкость хранятся только в `localStorage` вашего
браузера. Аналитики нет, наружу уходят лишь запросы за тайлами карты к
OpenStreetMap и за шрифтами к Google Fonts.
