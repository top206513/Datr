# Railway Last

Веб-приложение для планирования свидания: карта проверенных мест, отсчёт до встречи,
атмосферный музыкальный плеер и чек-лист подготовки — всё на одной странице.

> «Последний поезд уходит в 00:41. Всё, что нужно успеть до него, — здесь».

Проект вырос из простой мысли: идеальный вечер — это не импровизация, а десяток
заранее закрытых мелочей. Приложение держит их в одном месте и оставляет вам
только сам вечер.

---

## Возможности

### 🗺 Карта и локации

- Двенадцать кураторских мест на интерактивной карте (Leaflet + OpenStreetMap).
- Фильтры по категориям (виды, прогулка, ужин, культура, кофе, поздний вечер),
  избранное и поиск по названию, району и тегам.
- Детальная карточка: описание, личный совет, рейтинг, бюджет, лучшее время,
  продолжительность, теги и точные координаты — с копированием в буфер и
  переходом во внешние карты.
- Список и карта синхронизированы: наведение подсвечивает точку, клик по точке
  открывает карточку. Любое место можно назначить местом свидания — оно попадёт
  в шапку и в виджет отсчёта.
- Если подложка карты не загрузилась (нет сети), точки и карточки продолжают работать.

### ⏳ Таймер обратного отсчёта

- Дни, часы, минуты и секунды с анимацией смены разрядов и корректным русским
  склонением («1 день», «2 дня», «5 дней»).
- Дата, название вечера и выбранное место сохраняются в `localStorage`.
- Отсчёт считается от системных часов, а не накоплением тиков, — не сбивается
  после сна вкладки; за час до встречи виджет начинает «гореть».
- Отдельное состояние для уже прошедшей даты.

### 🎵 Музыкальный плеер

Плеер не проигрывает файлы — он **синтезирует музыку прямо в браузере** через
Web Audio API. Ни одного мегабайта ассетов, полная работа офлайн.

- Четыре трека, описанных как партитуры: сетка аккордов, мелодическая фраза,
  темп, тембр и плотность шумовой подложки (см. `src/data/tracks.ts`).
- Голоса: бас, педальный пад из трёх расстроенных осцилляторов, ведущая мелодия
  с лёгким портаменто и редкие колокольчики. Всё это идёт через реверберацию на
  сгенерированной импульсной характеристике и лимитер.
- Play/pause, предыдущий/следующий трек, перемотка по прогресс-бару, громкость
  (сохраняется), плейлист, эквалайзер-визуализатор, автопереход к следующему треку.
- Ноты планируются окнами вперёд (lookahead 0.4 с), поэтому перемотка и пауза
  отзываются мгновенно и не «уезжают» по времени.

### ✅ Чек-лист подготовки

- 14 пунктов в трёх разделах: «за несколько дней», «образ», «в день свидания» —
  купить цветы, подтвердить время, погладить рубашку, выйти на 15 минут раньше.
- У каждого пункта — короткая подсказка, зачем он нужен.
- Свои пункты добавляются и удаляются, прогресс считается кольцевым индикатором,
  отметки переживают перезагрузку, есть сброс.

### 🩷 Оформление

Визуальный язык вдохновлён песней **Cupid** группы FIFTY FIFTY: тёплый градиент
от солнечного жёлтого к коралловому, чёрный текст без засечек, много воздуха и
собственный знак — сердце, пробитое стрелой (он же иконка приложения).

Материал интерфейса — Liquid Glass. Он собран в двух вариантах, и приложение
само выбирает подходящий.

#### WebGL-сцена (основной путь)

Фон и все поверхности, лежащие на нём, рисует один фрагментный шейдер
(`src/gl/`) в холсте под содержимым страницы:

- **Форма через SDF.** Каждая панель — знаковое поле расстояний до
  прямоугольника со скруглением. По нему берётся нормаль (аналитически, без
  конечных разностей) и глубина, а по глубине строится кривая линзы: центр
  плоский, у кромки изгиб максимальный.
- **Преломление без текстур.** Фон процедурный, поэтому преломление — это
  повторный расчёт той же формулы в смещённых координатах. Ни одного
  фреймбуфера, ни одной текстуры, ни одного чтения из GPU; один draw call на
  кадр из одного треугольника.
- **Хроматическая аберрация** — три расчёта фона с разной силой смещения,
  по одному на канал.
- **Слияние каплей** — панели рядом объединяются мягким минимумом (`smin`),
  как metaball, а не пересекаются прямоугольниками.
- **Блики** берут направление света из наклона устройства.

Что сделано ради плавности: плотность пикселей ограничена 1.5× и сама падает
до 0.75×, если кадры проседают; в покое частота снижается до 30 к/с, а во
время прокрутки возвращается к полной, иначе стекло отстаёт от своей карточки;
при уходе вкладки в фон цикл останавливается; все чтения раскладки собраны в
один блок без записей между ними; панели за пределами экрана отбрасываются.

Сцена не включается, если WebGL недоступен или рендер программный
(`failIfMajorPerformanceCaveat`) — гонять шейдер на процессоре хуже, чем не
гонять вовсе.

#### CSS-стекло (запасной путь и плавающие элементы)

Шапка, плеер и модальное окно висят над содержимым страницы, а WebGL не видит
пиксели DOM под собой — эти элементы остаются на `backdrop-filter`, иначе они
перестанут показывать текст за собой. Тем же путём идёт всё приложение, если
сцена недоступна:

- **Рефракция.** Для каждой стеклянной поверхности генерируется 2D-карта
  смещения (`src/lib/liquidGlass.ts`): красный канал задаёт сдвиг по X,
  зелёный — по Y, 128 = ноль. `feDisplacementMap` двигает по ней пиксели фона,
  и фильтр подключается через `backdrop-filter: url(#…)`.
- **Края работают сильнее центра.** Карта нейтральна в середине и содержит
  градиент только в полосе по краю, повторяющей скругление элемента. Полоса
  размывается — переход идёт по кривой, как у линзы, а не ступенькой.
- **Хроматическая аберрация.** Смещение считается трижды с чуть разной силой,
  каналы R, G и B разбираются `feColorMatrix` и собираются обратно через
  `screen`. Цветной ободок виден только у кромки — там, где кривизна выше.
- **Кромка.** Тонкий ободок в 1.5 px, вырезанный маской из двух прямоугольников,
  поэтому он точно повторяет скругление. По нему коническим градиентом катится
  свет — именно кромка читается как толщина стекла; без неё панель выглядит
  просто «прозрачным прямоугольником».
- **Живые блики.** Отдельный слой поверх материала: на телефоне он следует за
  гироскопом, на десктопе — за курсором, а если сигнала нет, свет медленно
  дрейфует сам. Иначе стекло выглядит плоским на скриншоте и в статике.
- **Толщина зависит от размера.** Ширина кромки и сила смещения считаются от
  габаритов элемента, поэтому свёрнутая «пилюля» плеера — тонкое стекло, а
  развёрнутая карточка заметно толще и с более глубокой рефракцией.

Рефракция в этом пути включается только там, где браузер принимает ссылку на
SVG-фильтр в `backdrop-filter` (сегодня это Chromium). Safari и Firefox
получают тот же материал без искажения — тинт, размытие, блики и кромку; это
определяется через `CSS.supports` и переключается само.

Из оригинального материала не реализовано: HDR-подсветка при касании, подхват
цвета ярких объектов рядом и автопереключение контента на светлый над тёмным
фоном — для этого в вебе нет ни API, ни доступа к пикселям страницы.

Типографика — системная: на Apple-устройствах это SF Pro, на остальных Inter.
Адаптивно от 360 px, анимации на Framer Motion, поддержка `prefers-reduced-motion`,
доступные состояния фокуса и корректные ARIA-подписи.

## Стек

| Что | Чем | Почему |
| --- | --- | --- |
| Каркас | React 19 + TypeScript (strict) | Типы на доменной модели ловят ошибки до рантайма |
| Сборка | Vite 8 | Мгновенный dev-сервер, сборка за ~0.4 с |
| Стили | Tailwind CSS 4 | Дизайн-токены живут в `@theme` прямо в CSS |
| Анимации | Framer Motion | Layout-анимации фильтров и списков «из коробки» |
| Карта | Leaflet + CARTO Positron | Без API-ключей и лимитов; светлая минималистичная подложка |
| Стекло | WebGL 1 | SDF-панели и преломление фона одним шейдером |
| Звук | Web Audio API | Музыка синтезируется, а не грузится |
| Тесты | Vitest | 43 теста на логику времени, синтеза и материала стекла |
| Хранение | `localStorage` | Данные не покидают браузер |

Внешних сервисов, ключей и бэкенда нет — приложение полностью статическое.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

Другие команды:

```bash
npm run build      # проверка типов + продакшен-сборка в dist/
npm run preview    # локальный просмотр собранной версии
npm run test       # прогон тестов
npm run typecheck  # только проверка типов
```

Требуется Node.js 20+.

### Открыть на телефоне

**Вариант 1 — GitHub Pages (постоянная ссылка).** В репозитории уже лежит
workflow `.github/workflows/deploy.yml`: он собирает проект, прогоняет тесты и
публикует `dist/` при каждом пуше в рабочую ветку.

Один раз нужно включить Pages: **Settings → Pages → Build and deployment →
Source: GitHub Actions**. После этого запустите деплой (вкладка **Actions** →
*Deploy to GitHub Pages* → **Run workflow**) — через пару минут сайт будет
доступен по адресу `https://<пользователь>.github.io/Datr/`.

**Вариант 2 — по локальной сети.** Если компьютер и телефон в одном Wi-Fi:

```bash
npm run dev -- --host
```

Vite покажет строку `Network: http://192.168.x.x:5173/` — этот адрес и нужно
открыть в браузере телефона.

**Добавить на домашний экран.** Открытое приложение можно установить как обычное:
на Android — меню браузера → «Установить приложение», на iPhone — «Поделиться» →
«На экран Домой». Запустится на весь экран, без адресной строки.

## Как поменять содержимое под себя

- **Свои места** — `src/data/locations.ts`. Координаты берутся с любой карты;
  карта сама подстроит масштаб под новый набор точек. Стартовый центр — `CITY_CENTER`.
- **Свои пункты подготовки** — `src/data/checklist.ts` (или прямо в интерфейсе,
  через форму внизу раздела).
- **Своя музыка** — `src/data/tracks.ts`: корневая нота в герцах, сетка аккордов
  в полутонах, мелодическая фраза (32 восьмых = 4 такта), темп, тембр и плотность шума.
- **Палитра и шрифты** — блок `@theme` в `src/index.css`.

## Приватность

Дата, отметки, избранное и громкость хранятся только в `localStorage` вашего
браузера. Аналитики нет, наружу уходят лишь запросы за тайлами карты к
OpenStreetMap и за шрифтами к Google Fonts.
